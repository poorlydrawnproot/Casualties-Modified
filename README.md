# Casualties:Modified 
A Save Editor for the game Casualties:Unknown. <br>
This build functions on both Demo and Release versions (obviously..) 
## How 2 Build
Run build PS1 script.. that's it. Want a medal? Too bad. <br>
Make sure your save file is present at:
```
%USERPROFILE%\AppData\LocalLow\Orsoniks\CasualtiesUnknown\save.sv
```
If it is NOT there, then you have an issue to address. <br>
press F1 for help if you need it. <br>
